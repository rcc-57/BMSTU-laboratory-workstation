# АКИП-2205 — сборка из исходников и проверка на стенде Windows

Программа на C собирается и работает **на лабораторном ПК**. Прошивать мультиметр для этого проекта не требуется. Его штатная прошивка принимает команды по интерфейсному кабелю и возвращает показания. Режим и диапазон выбирают на передней панели прибора. Из окна на ПК можно запросить значение, начать и остановить опрос, сохранить историю и отправить команду сброса.

## 1. Подготовить ПК и исходный код

1. На ПК с Windows 10/11 x64 установите **Visual Studio 2022** или **Build Tools 2022**. В установщике выберите **Desktop development with C++**, компилятор **MSVC v143 x64/x86** и **Windows SDK**. Установите **CMake 3.21 или новее** с CTest и включите добавление в PATH. Для клонирования потребуется Git for Windows. Для окна нужен видеодрайвер с OpenGL 3.2 Core. [Установщик Build Tools 2022](https://aka.ms/vs/17/release/vs_BuildTools.exe) · [CMake](https://cmake.org/download/) · [Git for Windows](https://gitforwindows.org/).
2. Перенесите **текущую рабочую папку проекта** на ПК, например в `C:\lab\cimgui`. Проверьте наличие `measurement_app\START-WINDOWS.cmd`, `measurement_app\akip_device.c`, корневого `cimgui.cpp` и `imgui\imgui.cpp`. Каталог `build` с другого компьютера оставьте на нём. Если команда уже опубликовала эти изменения в своей ветке, вместо копирования можно клонировать проект:

   ```powershell
   git clone --recurse-submodules --branch serega-vanek-yarik-branch https://github.com/rcc-57/BMSTU-laboratory-workstation.git C:\lab\cimgui
   ```

3. На первом запуске CMake скачает исходники GLFW 3.4 с GitHub. **Если в лаборатории нет интернета**, заранее перенесите вместе с проектом заполненную папку `imgui`, а исходники GLFW 3.4 положите в `deps\glfw` от корня проекта. Проверьте наличие `deps\glfw\CMakeLists.txt` и `deps\glfw\src`. Для этой рабочей копии их можно взять из `build/measurement/_deps/glfw-src` на исходном компьютере. Скрипт сам обнаружит эту папку. Инструменты сборки и USB-драйвер тоже подготовьте заранее.

## 2. Собрать и открыть окно

Запустите в новом PowerShell на Windows, подставив свой путь:

```powershell
cd C:\lab\cimgui
.\measurement_app\START-WINDOWS.cmd
```

Тот же скрипт можно запустить двойным щелчком. Он каждый раз вызывает CMake для сборки актуальных исходников в **Release x64**, выполняет CTest и запускает только что собранную программу. При ошибке скрипт останавливается и оставляет сообщение в консоли.

| Что проверяется | Что должно произойти |
| --- | --- |
| Сборка и тесты протокола | CTest сообщает о пройденном тесте `akip_protocol` и выводит `100% tests passed`. Прибор для этого шага можно оставить отключённым. |
| Отрисовка, обработка событий и закрытие окна | Первое окно изменит размер и закроется само. Дождитесь строки `GUI closed cleanly after 120 rendered frames.` |
| Обычный запуск | Откроется **Measurement Instrument Control** со статусом **Disconnected** и полем **No data**. Можно выбирать порт. |

Для раздельной диагностики выполните команды по очереди из корня проекта. Переходите к следующей после успешного завершения предыдущей:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\measurement_app\build-windows.ps1
.\build\measurement-windows\Release\measurement_control.exe --smoke-test
.\build\measurement-windows\Release\measurement_control.exe
```

## 3. Подключить мультиметр и проверить обмен

Для прогона возьмите проводной АКИП-2205, его штатный интерфейсный кабель, щупы и батарейку 1,5 В. Руководство прибора требует заземлённый ПК при проводной связи.

| Шаг | Что сделать | Признак успеха |
| --- | --- | --- |
| 1. Найти кабель | Включите прибор. В Windows откройте **Диспетчер устройств → Порты (COM и LPT)**, затем подключите штатный USB-кабель. Запишите номер появившегося **Silicon Labs CP210x USB to UART Bridge**, например COM7. Для проводного соединения Pair не требуется. | Появился COM-порт без значка ошибки. Это подтверждает готовность USB-моста. |
| 2. Подтвердить обмен | Закройте DMMVIEW_G и другие программы, использующие порт. В нашем окне нажмите **Refresh ports**, выберите тот же номер, оставьте **CRLF (default)** и нажмите **Connect**. Программа сама задаёт 9600 бод, 8N1. | В журнале сначала **TX ONL**, затем **RX ACK**, в статусе **Online**. Это ответ на запрос связи. Модель сверьте по маркировке прибора. |
| 3. Сверить показание | На мультиметре выберите постоянное напряжение **DCV**. Чёрный щуп вставьте в **COM**, красный во вход **V/Ω**. Измерьте батарейку и нажмите **Read once**. Для наглядной проверки поменяйте щупы местами на полюсах батарейки и повторите чтение. | Счётчик **Measurements** увеличился после каждого запроса. Режим, единица, знак и устойчивое значение совпадают с дисплеем с учётом его обновления. При смене полярности знак изменился и в окне. |
| 4. Проверить историю | Нажмите **Start acquisition**, дождитесь нескольких отсчётов, затем **Stop acquisition**. В поле **CSV path (new file)** задайте новое имя и нажмите **Export CSV**. Относительный путь при запуске скриптом отсчитывается от папки скрипта. | На графике появились точки. После ответа на последний отправленный запрос счётчик перестал расти. В CSV есть строки с временем, числом, единицей и признаком valid=1. |
| 5. Проверить управление | Сохраните CSV и снимите щупы с батарейки. Сброс очистит историю в окне. При остановленном опросе дождитесь **request: idle**. Оставьте USB подключённым. Нажмите **Reset instrument → Send RST** и наблюдайте дисплей прибора. | Журнал содержит **TX RST**, **RX RST ACK**, затем новый **TX ONL** и **RX ACK**. После возврата **Online** проверьте режим DCV и снова измерьте батарейку через **Read once**. |
| 6. Проверить повторный запуск | Нажмите **Disconnect**, закройте окно, затем отсоедините USB. Подключите кабель, запустите приложение и повторите шаги 1–3. | COM снова открывается, прибор отвечает на ONL и возвращает новое показание. |

Строка **TX** подтверждает отправку со стороны ПК. Для протокола DMMVIEW_G запрос чтения выглядит как `#RD?\r\n`, команда сброса — `#RST\r\n`. Сброс описан производителем как действие, эквивалентное включению прибора. Конкретный рисунок на дисплее при запуске зависит от прибора. Подтверждение сброса берите из строки **RX RST ACK**. Если повторный ONL завершился тайм-аутом, дождитесь готовности прибора и попробуйте **Connect** вручную. Зафиксируйте отдельно, потребовалось ли ручное подключение.

## 4. Когда переходить к следующему этапу

Базовый прогон принят, когда выполнены все шесть шагов, в том числе получено новое измерение после сброса и после повторного открытия порта. Сохраните три результата:

- номер COM и два значения DCV с единицами и знаком, сверенные с экраном;
- CSV остановленной серии с несколькими реальными отсчётами;
- текст из **Copy diagnostics** после сброса и нового чтения, **до закрытия программы**. Укажите, наблюдалась ли реакция дисплея и восстановилась ли связь автоматически.

Если шаг сорвался, запишите его номер, ожидаемый и фактический результат и приложите диагностику. Следующий этап после успешного прогона — проверить остальные нужные режимы на физических образцах. Для температуры и диапазонов ёмкости с кодами 5–7 сохраняйте одновременно кадр RD, число и единицу с дисплея: они нужны для уточнения декодера.

## Если что-то пошло не так

| Наблюдение | Действие |
| --- | --- |
| Команда cmake или ctest не найдена | В новом PowerShell выполните `cmake --version` и `ctest --version`. Добавьте каталог `bin` установленного CMake в PATH. |
| CMake не нашёл Visual Studio 17 2022, компилятор или SDK | Откройте Visual Studio Installer и проверьте компоненты из шага 1. |
| Ошибка получения imgui или GLFW | Для Git-копии из корня выполните `git submodule update --init --recursive`. Для ПК без сети используйте исходники обеих зависимостей из шага 1. |
| Окно не открылось, в консоли GLFW/OpenGL error | Сохраните текст ошибки. Проверьте драйвер видеокарты и повторите запуск на локальном рабочем столе. |
| CP210x не появился | Проверьте питание и кабель. Установите подходящий Windows VCP-драйвер с [официальной страницы Silicon Labs](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers). Подключите кабель снова. В PowerShell список портов покажет `[System.IO.Ports.SerialPort]::GetPortNames()`. |
| Windows error 2 или 5 | Для 2 обновите список COM и сверьте номер. Для 5 закройте штатное ПО, терминал или второй экземпляр приложения. |
| Порт открыт, но нет ACK | Проверьте, что выбран именно подключённый мультиметр. Сверьте связь в DMMVIEW_G и закройте его. В описании кадра указано CRLF, а в примерах встречается CR. При тайм-ауте попробуйте **CR (compatibility)** и снова **Connect**. |
| Есть ACK, но RD даёт NAK | Выйдите на мультиметре из просмотра памяти в режим обычного измерения. Повторите **Read once**. |
| RX bytes растёт, но есть invalid/unexpected или значение расходится | Скопируйте **Copy diagnostics**, запишите режим, диапазон и значение на дисплее. Для разбора нужны фактические RX-байты. |
| После случайного обрыва связи возник тайм-аут | Закройте приложение, переподключите кабель, запустите снова и сверьте актуальный COM. |
| CSV creation failed | Выберите доступную для записи папку и новое имя файла. Существующий CSV сохраняется. |

## Где в коде проходит одно измерение

Кнопка **Read once** в `measurement_app/instrument_ui.c` вызывает `akip_device_read_once`. Функция `akip_command` в `measurement_app/akip_protocol.c` формирует байты запроса. **`measurement_app/akip_device.c` принимает реальные байты из COM-порта** и передаёт их в парсер. После разбора ответа `RD` функция `accept_event` обновляет последнее значение и историю. График показывает последовательные показания мультиметра с выбранным интервалом опроса.

В комплектной спецификации производитель указывает соответствие SCPI и задаёт точный формат команд для этой модели. Кнопкам подключения, чтения и сброса соответствуют `#ONL`, `#RD?` и `#RST` с окончанием строки. Формат кадров описан на с. 2–5, формат DCV — на с. 12 и 16. Подключение кабеля описано в разделе *Wired Communication* на с. 30 руководства. [Протокол DMMVIEW_G](<../DMM 2205/DMMVIEW_G(2.2)/DMMVIEW_G Communication Protocol(0.0).pdf>) · [Руководство прибора](<../DMM 2205/Product User Manual.pdf>).
